## 基本约定
#### 方向规定
俯视时，从几何中心向核心板的方向是前进的方向，四个电机分别为lf,lb,rf,rb  
lf,rb电机逆时针转;rf,lb电机顺时针转  
实测在TOF超距时返回值为8192，建议大于1400时直接置为1400  
当前imu安装方向为水平向前为x，水平向右为y，竖直向下为z  
定义坐标系为水平向前为x，水平向右为y，竖直向下为z  

pitch：机头向上，即前段高后端低时为正，此时应表示为向后飞，反之为负  
roll:左端高右端低为正，此时应表示向右飞，反之为负  
yaw:向顺时针为正，逆时针为负
实测前倾与右倾时相应符合逻辑  

图传画面上方为前进方向，当前相机垂直向下  
MT9V03X_H MT9V03X_W 120 * 188  
cam_down.centers[0][0]表示从上到下数的行数，在最上方为0  
cam_down.centers[0][1]表示从左到右数的列数，在最左方为0

#### 控制逻辑
现在通过“视觉环->角度环->角速度环”三串级结构控制飞行状态  

#### 屏幕使用
屏幕以输出文字和数字信息为主。ips200_show_xxx函数中，前两个参数代表位置的x,y坐标,  
如有最后一个参数，通常代表字符长度。一个字符大约占据x方向10个像素，y方向16个像素。

## 按键对象 (`dev_key`) 内部状态与变量说明
这些变量经过了硬件消抖和边沿提取

| 变量名 | 数据类型 | 含义说明 | 典型应用场景 |
| :--- | :--- | :--- | :--- |
| **`event`** | `Key_Event_e` | **当前周期的瞬间动作事件**。<br>只有在动作发生的那一个周期（10ms内）会有值，其余时间均为 `KEY_EVT_NONE`。 | 用于触发单次动作。例如：短按切换模式、长按解锁无人机。 |
| **`is_pressed`** | `uint8_t` | **当前的稳定长效状态**。<br>`1` = 当前正处于按住/闭合状态<br>`0` = 当前处于松开/断开状态。 | 用于电平保持类的逻辑。例如：判断拨码开关当前是否打在 ON 的位置。 |

**`event` (动作事件) 的枚举值说明：**
* `KEY_EVT_NONE` (0)：无动作发生（绝大部分时间的默认值）。
* `KEY_EVT_DOWN` (1)：**按下瞬间**（下降沿），刚接触的那一刻触发一次。
* `KEY_EVT_UP` (2)：**松开瞬间**（上升沿），按下时间超过一秒，刚抬起的那一刻触发一次。
* `KEY_EVT_SHORT` (3)：**短按**，按下并松开，且按住的时间小于长按阈值（1秒）时，在松开的瞬间触发一次。
* `KEY_EVT_LONG` (4)：**长按**，按住不动的时间达到设定阈值（1秒）的瞬间触发一次（此时手还未松开）。

---

| 变量名 | 数据类型 | 含义说明 | 典型应用场景 |
| :--- | :--- | :--- | :--- |
| **`press_time`** | `uint16_t` | **已按下的持续时间**（单位：ms）。<br>只要处于按下状态，该值就会不断累加；一旦松开立即清零。 | 用于自定义超长按逻辑（如按住3秒关机：`press_time >= 3000`）。 |
