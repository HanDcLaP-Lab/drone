## 基本约定
#### 方向规定
俯视时，从几何中心向核心板的方向是前进的方向，四个电机分别为lf,lb,rf,rb  
lf,rb电机顺时针转;rf,lb电机逆时针转  
实测在TOF超距时返回值为8192，建议大于1400时直接置为1400  
当前imu安装方向为水平向前为x，水平向右为y，竖直向下为z  
定义坐标系为水平向前为x，水平向右为y，竖直向下为z  

pitch：机头向上，即前段高后端低时为正，此时应表示为向后飞，反之为负  
roll:左端高右端低为正，此时应表示向右飞，反之为负  
yaw:向顺时针为正，逆时针为负[已修改，符合右手系]  
实测前倾与右倾时相应符合逻辑  

图传画面上方为前进方向，当前相机垂直向下

#### 控制逻辑
现在通过“视觉环->角度环->角速度环”三串级结构控制飞行状态  

#### 屏幕使用
屏幕以输出文字和数字信息为主。ips200_show_xxx函数中，前两个参数代表位置的x,y坐标,  
如有最后一个参数，通常代表字符长度。一个字符大约占据x方向10个像素，y方向16个像素。  
https://github.com/but0n/Avem.git
